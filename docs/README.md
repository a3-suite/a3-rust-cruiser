# プロジェクト文書

`docs/` はプロジェクトの詳細文書ルートです。ルートの `README.md` は成果物の入口として、ここから詳細へ接続します。

## 文書クラス

- 要求・仕様・設計: SDD の current artifact（`sdd/dsl/requirements/`・`sdd/dsl/specs/`・`sdd/dsl/designs/`）を正本とし、`docs/` へ重複して保持しません。
- メモ: `docs/notes/`（非正本。正本へ昇格するときは内容を複製しません）
- 開発・保守の入口: [ルート開発ガイド](../DEVELOPMENT.md)
- 保守: `docs/maintenance/`
- 成果物運用: `docs/operations/`
- リリース: `docs/release/`
